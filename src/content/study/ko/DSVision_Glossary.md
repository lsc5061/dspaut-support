비파괴검사(NDT)와 위상배열 초음파 탐상(PAUT) 소프트웨어는 전문 영문 약어와 매개변수가 매우 많아 신입 엔지니어와 바이어들이 초기 조작 시 많은 혼란을 겪습니다. 

본 용어 사전은 DSVision 프로그램에 등장하는 핵심 단어들의 **학술적 정의**뿐만 아니라, **화면 상의 위치, 조작 목적, 그리고 실무 현장에서의 유용한 팁**을 체계적으로 풀이하여 즉각적인 이해를 돕습니다.

---

## 1. 상단 측정 데이터 (Header Data) 용어

화면 최상단에 실시간으로 수치 표출되는 용어들로, 검사원이 특정 게이트(A, B, I)를 터치하여 선택함에 따라 측정 약어 또한 동적으로 자동 전환됩니다 (예: Gate A 선택 시 PA/DA/SA, Gate B 선택 시 PB/DB/SB).

### %A (Amplitude, 진폭 백분율)
* **뜻**: 게이트 내에서 검출된 초음파 수신 에코(신호) 중 가장 높은 피크의 강도를 화면 수직 전체 높이(FSH) 대비 백분율(%)로 표시한 값입니다.
* **실무 활용**: 용접부 검출 기준 에코 높이(예: 80%)에 도달했는지 판별하거나 결함에 의한 감쇠 정도를 측정할 때 감도의 척도가 됩니다.

### P (Primary Distance / Projected Distance, 수평 투영 거리)
* **뜻**: 탐촉자의 앞단(Wedge Toe) 기준점으로부터 결함이 검출된 지점까지의 **수평 직선거리(mm)**를 나타냅니다.
* **실무 활용**: 시험체 표면의 어디쯤을 파내야 결함이 나오는지를 평면 좌표상에서 확인하는 데 사용됩니다.

### D (Depth / True Depth, 수직 깊이)
* **뜻**: 시험체의 윗면(탐상 표면)으로부터 결함이 존재하는 지점까지의 **수직 깊이(mm)**를 나타냅니다.
* **실무 활용**: 수동 탐촉자 계산기 없이도 결함이 시험체 내부 몇 mm 깊이에 위치하는지 곧바로 파악할 수 있는 가장 핵심적인 수치입니다.

### S (Sound Path, 음정 거리)
* **뜻**: 탐촉자 소자로부터 방출된 초음파 빔이 실제 진행하여 결함(반사체)에 부딪히고 돌아온 **대각선 총 진행 거리(mm)**를 뜻합니다.
* **실무 활용**: 빔의 전파 감쇠량 계산 및 매질 내부의 실제 물리적 이동 거리를 확인하는 데 쓰입니다.

### Scan / Index (스캔 및 인덱스 축 거리)
* **뜻**: **Scan(Blue)**은 탐촉자가 앞뒤로 진행하는 축의 현재 이동 거리(mm)를 뜻하며, **Index(Green)**는 진행 축에 수직인 폭 방향 오프셋 거리(mm)입니다.
* **실무 활용**: 스캐너(인코더) 연동 시 결함의 3차원 위치 좌표를 특정하기 위한 X-Y 맵의 좌표값 역할을 합니다.

## 2. 송수신 및 빔 제어 용어 (Pulse & Probe)

### Config (동작 모드)
* **뜻**: 장비의 하드웨어 스위칭 모드 설정으로 `PA`(Phased Array 부채꼴), `LA`(Linear Array 선형 컬러 이미지), `Conventional`(단일 초음파) 중 선택합니다.
* **실무 활용**: 검사 대상에 따라 부채꼴 주사가 필요하면 PA 모드를, 표면 직하의 단순 두께 매핑이나 선형 조사가 필요하면 LA 모드를 사용합니다.

### Focal Law (빔 조향 법칙)
* **뜻**: 위상배열 소자들의 발사 시간차(Delay)를 연산하여 특정 범위의 각도로 빔을 굴절시키는 조향 공식의 집합입니다.
* **실무 활용**: `Angle Start`(시작각)와 `Angle Stop`(종료각) 범위를 입력하여 탐촉자를 고정시킨 채 다양한 각도(최대 89도)의 빔을 쏘아 용접 홈 내부 각도에 따른 미세 균열을 놓치지 않고 검출하게 만듭니다.

### RF Mode (Radio Frequency 모드)
* **뜻**: 수신된 초음파 파형을 한 방향으로 정류하지 않고, 위아래로 진동하는 날것의 양방향 원본 파형 상태로 표출하는 기능입니다.
* **실무 활용**: **Conventional 모드에서만 활성화**되며, 두께가 매우 얇은 박판이나 미세 노이즈 분석 시 신호의 극성(Phase) 변화를 감지할 때 활용됩니다.

### PA Dual (이중 위상배열 모드)
* **뜻**: 하나의 탐촉자 뭉치 내부에 송신 전용 소자(Tx)와 수신 전용 소자(Rx)를 물리적으로 분리하여 동작시키는 핀맵 스위칭 모드입니다.
* **실무 활용**: 장비 내부의 32소자 스위칭 보드와 연동되어 Tx 1-16 / Rx 33-48 채널 격리를 보장하며, 오스테나이트 강종이나 두꺼운 모재 검사 시 표면 근방 불감대(Dead Zone)를 없애고 노이즈를 획기적으로 줄여줍니다.

## 3. 시험체 및 하드웨어 정렬 용어 (Specimen & Wedge)

### Legs (반사 가이드라인)
* **뜻**: 초음파가 시편 바닥면과 표면을 오가며 지그재그로 반사되는 경로를 S-Scan 상에 초록색 수평 점선으로 표시해 주는 기능입니다.
* **실무 활용**: 시험체 두께(`Thickness`) 입력값에 연동되어 `B0`(바닥면 반사), `T1`(표면 반사) 선을 뿌려주며, 결함 신호가 바닥 반사 이후(1-Skip) 경로에서 나왔는지 직접적인 Leg 구분을 돕습니다.

### Primary Axis / Height (웨지 장착 오프셋)
* **뜻**: `Wedge = Enable` 모드 시 필수 연산 파라미터로, **Primary Axis**는 웨지 앞단(Toe)으로부터 첫 소자까지의 수평 거리(음수 값 기입), **Height**는 웨지 내 첫 소자의 수직 높이를 뜻합니다.
* **실무 활용**: 웨지 형상 라이브러리(Wedge Wizard) 적용 시 자동 대입되며, 이 오프셋이 정확해야만 S-Scan에 용접 단면도가 정확한 기하학적 위치에 겹쳐서 오버레이 표출됩니다.

## 4. 측정 및 보정 용어 (Gate & Calibration)

### Auto Gain & Auto FSH
* **뜻**: **Auto Gain**은 버튼 하나로 현재 에코 피크를 설정한 **Auto FSH(목표 높이, 기본 80%)** 수치에 맞춰 수동 볼륨 조절 없이 신호를 정규화하는 자동 증폭 보정 기능입니다.
* **물리 공식**: $\Delta\text{Gain} = 20 \log_{10}(\text{목표 \%} / \text{현재 피크 \%})$
* **실무 활용**: NDT 현장 규격(ASME 등)에서 요구하는 80% FSH 감도 교정 작업을 수동 클릭 여러 번 할 필요 없이 1초 만에 완료하여 생산성을 배가시킵니다.

### Gate I (Interface Gate) & Sync (동기화)
* **뜻**: **Gate I**는 표면 에코를 추적하는 독립 게이트이며, **Sync**는 이 표면 에코 발생 시점을 시간 영점(T=0)으로 강제 동기화하는 기능입니다.
* **실무 활용**: 수조 스캔이나 프로브 밀착 흔들림으로 인해 물의 두께(Water Path)가 변하더라도, Gate A와 B가 항상 표면 기준선으로부터 일정한 상대 깊이만을 유지하며 결함을 안정적으로 감시하도록 실시간 추적을 제어합니다.

### Edge / Peak Detection (검출 모드)
* **뜻**: 게이트 내 신호 판정 기준으로, **Peak**는 가장 높은 파형 꼭짓점 강도를 읽고, **Edge**는 파형이 상승하며 게이트 임계값(Threshold) 선을 처음 뚫고 올라가는 진입점을 읽습니다.
* **실무 활용**: 최대 반사 진폭 검출에는 Peak를 쓰고, 정밀한 두께 측정이나 결함의 최초 시작 경계 시간을 잡을 때는 Edge 모드가 유리합니다.

### Encoder Calibration (인코더 보정)
* **뜻**: 스캐너 바퀴 회전에 의한 펄스 카운트를 실제 정밀한 밀리미터(mm) 단위 거리로 보정하기 위해 이동 펄스 평균값을 역산해 주는 기능입니다.
* **실무 활용**: 시작점에서 누르고 정확히 100mm 굴린 뒤 정지점을 눌러 실측치 "100"을 입력하면 자동으로 해상도가 보정되어 구동 중 데이터 누락 오차율을 0%에 가깝게 맞춰줍니다.

### 6dB Drop Method (6데시벨 감쇠법)
* **뜻**: 결함 피크 지점(Ref. Cursor 지정)에서 진폭이 반(-6dB down, 예: 80% ➔ 40% FSH)으로 떨어지는 양쪽 끝단(Meas. Cursor 지정)의 거리 차이로 결함 크기를 측정하는 기법입니다.
* **실무 활용**: 화면에 표시되는 **ΔH(가로 편차 = 결함 길이)** 및 **ΔV(세로 편차 = 결함 높이)** 수치를 읽어 결함의 물리적 면적과 유해도를 최종 판정합니다.
